# 🌍 KRIBI PORT CONNECT

**La bourse fret digitale qui remplit tes camions au Cameroun**

## 📋 Description

KPC est une plateforme de mise en relation entre :
- **Transitaires** qui ont du fret à transporter
- **Chauffeurs/Camionneurs** qui cherchent du fret retour
- **Chargeurs**/exportateurs vers le Tchad et la RCA

**Problème résolu :** 45% des conteneurs sortent vides du Port Autonome de Kribi. Les camionniers perdent 2-3 jours à chercher du fret.

## 🚀 Services

- Mise en relation en moins de 15 minutes
- Réseau de 40+ camionneurs actifs
- Commission uniquement si livraison effectuée
- Suivi WhatsApp jusqu'au POD
